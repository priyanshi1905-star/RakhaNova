# 🚨 RakshaNova

### AI-Powered Disaster Relief Planner

**Smarter Decisions. Safer Responses. Stronger Communities.**

RakshaNova is an AI-powered disaster relief planning concept designed to support emergency response by helping identify blocked roads, plan safer evacuation routes, locate nearby shelters, and coordinate rescue resources.

Developed as part of the **AI in Sustainable Development Hackathon**, RakshaNova explores how technology can contribute to more efficient disaster management.

---

## 🌍 Problem Statement

During natural disasters and emergencies, rescue operations often face challenges such as:

* Blocked roads and disrupted transportation.
* Difficulty identifying safe evacuation routes.
* Limited availability of nearby shelters.
* Challenges in coordinating rescue resources.
* Changing weather conditions.

These challenges can make emergency planning more complex and time-sensitive.

## 💡 Our Solution

RakshaNova aims to bring essential disaster response information together through a unified planning interface.

The project explores how mapping technologies, intelligent route planning, and weather information can support better emergency response decisions.

## ✨ Key Features

* 🗺️ **Interactive Mapping:** Visual representation of disaster-affected areas.
* 🚧 **Road Blockage Identification:** Representing blocked routes in the demonstration scenario.
* 🛣️ **Evacuation Route Planning:** Exploring safer route selection.
* 🏠 **Shelter Identification:** Displaying available emergency shelters.
* 🚑 **Rescue Coordination:** Representing rescue vehicle availability.
* 🌦️ **Weather Integration:** Incorporating weather information into disaster planning.

## 📍 Project Demonstration

For our Pune-based demonstration, we explored a disaster scenario involving:

| Component          | Quantity |
| ------------------ | -------: |
| Blocked Roads      |        5 |
| Emergency Shelters |        3 |
| Rescue Vehicles    |        2 |

This scenario demonstrates how disaster-related information can be organised to support emergency planning.

   ```bash

   ```

3. Open `index.html` in your browser.
